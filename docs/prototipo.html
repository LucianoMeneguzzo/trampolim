DESAFIOS / API DE PEDIDOS
AM
AbertoINTERMEDIÁRIO

Construa uma API de pedidos que uma loja realmente usaria.

Crie uma API REST clara, organizada e documentada para registrar clientes, produtos e pedidos — pensando na experiência de quem vai consumir o serviço.

O contexto

Uma pequena loja precisa sair da planilha e passar a registrar pedidos em um sistema confiável. Seu desafio é modelar os recursos principais, criar os endpoints e documentar as decisões que tomou.

O que esperamos da entrega

  • ✓Endpoints para criar, listar e atualizar pedidos
  • ✓Validação de dados e respostas de erro consistentes
  • ✓Persistência com MySQL ou PostgreSQL
  • ✓README com instruções para rodar o projeto

Tecnologias sugeridas
